# Suyash Singh — Ultra 3D Portfolio

A clean, cinematic, space-inspired portfolio for **Suyash Singh**, a first-year B.Tech CSE student.

## Experience

The site is intentionally built as a lightweight experience rather than a giant framework project.

```text
OPEN
  ↓
SPACE / 3D HERO
  ↓
ABOUT
  ↓
LEARNING FLOW
  ↓
SKILLS + PROGRESS
  ↓
PROJECT UNIVERSE
  ↓
SOCIAL / CONTACT
```

## Core features

- Interactive Three.js star field
- Floating 3D planet and orbit
- Smooth camera movement
- Scroll-based depth zoom
- Mouse parallax
- Day / Night mode
- 4 saved accent colors
- LocalStorage theme persistence
- Responsive mobile navigation
- Animated skill progress bars
- GitHub, Gmail and social-card UI
- IntersectionObserver reveal animations
- Reduced-motion support
- No build step required

## Run locally

Open `index.html` in a modern browser.

For GitHub Pages, upload the complete folder to the repository root and select:

```text
Settings
→ Pages
→ Deploy from a branch
→ main
→ /(root)
→ Save
```

## Design direction

The visual language is based on:

- dark space atmosphere
- glass panels
- restrained neon accent
- oversized typography
- technical HUD details
- consistent rectangular / rounded cards
- responsive game-like navigation
